# Giao diện Việt–Anh

Phạm vi: toàn bộ giao diện web hiện có, gồm trang công khai, đăng nhập, tính WQI,
kết quả/lịch sử, Excel, quản trị và trạng thái loading/empty/error. Việc dịch không
hoàn thiện thay các nghiệp vụ còn stub hay xác minh độ chính xác của mô hình.

## Hành vi

- Lần đầu dùng `vi`; chỉ giá trị đã lưu `en`/`vi` được chấp nhận. Không tự dò ngôn ngữ trình duyệt.
- Người dùng chọn **Tiếng Việt / English** bằng nút có `aria-pressed`, dùng được bằng bàn phím.
- Lưu `localStorage['wqi.language']`. Storage bị chặn thì giữ lựa chọn trong bộ nhớ; xóa storage đưa về tiếng Việt ở tab nhận sự kiện.
- Ngôn ngữ dùng chung mọi màn hình, không lưu vào tài khoản/MongoDB, không thêm tiền tố URL.
- Thay đổi chỉ làm cập nhật nội dung React, không remount ứng dụng/form/map hoặc thay dependency tải dữ liệu.
- `html.lang`, tiêu đề theo trang và meta description thay đổi theo lựa chọn.
- Dữ liệu do người dùng nhập và tên địa lý từ nguồn giữ nguyên. Nhãn địa danh nền Goong/Esri do nhà cung cấp quản lý, không dịch hoặc đổi provider khi chọn ngôn ngữ.

## Tổ chức và thuật ngữ

Frontend dùng `i18next` và `react-i18next`. Catalog đóng gói cùng ứng dụng, không
gọi mạng để dịch. Các khóa semantic được nhóm theo tiền tố `common`, `auth`,
`home`, `map`, `quality`, `predictions`, `history`, `excel`, `imports`, `stations`,
`admin`, `users`, `settings`, `records`, `chart`, `report`, `messages`, `metadata`.
Catalog chứa cặp `[English, Vietnamese]`; kiểm thử yêu cầu đủ hai giá trị và cùng
tham số nội suy. Fallback tiếng Việt không thay cho việc sửa khóa thiếu.

| English | Tiếng Việt | Phân biệt |
|---|---|---|
| Monitoring station | Trạm quan trắc | Metadata/vị trí không chứng minh đã có dữ liệu đo. |
| Measurement record | Bản ghi quan trắc | Số liệu đo, khác prediction. |
| WQI prediction / calculation | Dự đoán / tính WQI | Kết quả mô hình, không tự công khai thành đo thực địa. |
| Calculation history | Lịch sử tính WQI | Lịch sử thuộc tài khoản. |
| Historical Data | Dữ liệu quan trắc | Màn hình tra cứu mẫu theo trạm/thời gian. |
| Import | Nhập dữ liệu | Giữ giá trị nguồn; khác batch inference. |
| Normalize | Chuẩn hóa | Gắn metadata cho dòng nguồn, không tự quy đổi đơn vị. |
| Pending review / Verified / Rejected | Chờ duyệt / Đã duyệt / Từ chối | Chỉ dịch nhãn, không đổi giá trị API. |
| Very good / Good / Medium / Poor / Bad / Heavily polluted | Rất tốt / Tốt / Trung bình / Xấu / Kém / Ô nhiễm rất nặng | Giữ nguyên sáu dải, màu, enum đã lưu. |
| Source units unverified | Đơn vị nguồn chưa xác minh | Không coi bản dịch là xác nhận đơn vị huấn luyện. |

Các nhãn bản đồ/trang chủ cũ có thang hiển thị năm mức vẫn giữ nguyên mốc/màu
hiện có trong thay đổi này. Không sửa thuật toán phân loại hay dữ liệu lịch sử để
làm giao diện song ngữ. Trang kết quả và badge prediction tiếp tục dùng sáu mức.

## Quy tắc phát triển

- Thêm copy mới bằng khóa có nghĩa, ví dụ `msg('common.home')`; không dùng nguyên câu làm khóa.
- Component đọc ngôn ngữ qua `useLocale()`; gọi `msg()` khi render. Không đưa locale vào dependency gọi API hoặc làm `key` của form/map.
- Toast có tham số dùng `MessageDescriptor` (`key`, `params`) để giữ dữ liệu gốc và đổi được khi đang hiển thị.
- `displayText` chỉ là adapter cho các bảng nhãn frontend cũ đã biết; không áp dụng lên tên người/trạm, ghi chú hoặc dữ liệu nguồn.
- Lỗi hiện có giữ nguồn thông báo tiếng Anh trong state, dịch khi render. `errorText` ưu tiên mã API; `messageText` nhận diện thông báo và mẫu lỗi có sẵn, lỗi lạ dùng câu an toàn, không đưa stack trace ra UI.
- Lỗi native HTML giữ thông báo nguồn và được cập nhật khi đổi ngôn ngữ; giá trị và luật validation không thay đổi.
- API/backend/shared contracts không import i18n của React và không phụ thuộc ngôn ngữ trình duyệt.

## Số, ngày và xuất/in

Ngày/số hiển thị dùng `vi-VN`/`en-US`; giữ precision và múi giờ vốn có của từng
ngữ cảnh. Trục ngày biểu đồ vẫn UTC; thời gian thông thường vẫn theo môi trường
trình duyệt như trước. Ô nhập số/date giữ dữ liệu máy và cách parse hiện có;
giao diện lịch native còn phụ thuộc trình duyệt/hệ điều hành.

Các hàm tạo CSV/Excel không nhận locale UI. Helper shared `qualityClassLabel`
giữ tiếng Anh để không làm đổi export. Nhãn WQI trên màn hình dùng helper riêng.
Article báo cáo được cố định `lang="en"`, ngày và phân loại tiếng Anh. Chức năng in
đặt tạm ngôn ngữ render thành English rồi phục hồi sau in/hủy/lỗi; không sửa lựa
chọn đã lưu. Dữ liệu tính toán, mã model, headers Excel, tên file và đơn vị không
bị dịch hoặc quy đổi.

## Kiểm thử

```powershell
npm run typecheck
npm run lint
npm run build
npm test
npm run ai:test
npx playwright test e2e/i18n.spec.ts
```

Browser tests cần web local đang chạy (`npm run dev:web`), Chromium đã cài
(`npx playwright install chromium`). Có thể chọn Chrome trên máy bằng biến môi
trường `E2E_CHANNEL=chrome` và đổi URL bằng `E2E_BASE_URL`. Bộ `i18n.spec.ts` chặn
và trả toàn bộ API bằng fixture trong browser, không kết nối hay ghi Atlas. Screenshot
ở `docs/local/screenshots/i18n/` là dữ liệu kiểm thử, không phải số liệu đo thực.

Các test giao diện cũ khai báo English làm fixture hồi quy; các test i18n mới kiểm
tra mặc định tiếng Việt và cả hai ngôn ngữ. E2E model thật dùng tài khoản/database
kiểm thử riêng, không chạy thao tác ghi trên Atlas dùng chung để nghiệm thu.

Điều kiện nghiệm thu: đủ khóa/param; đổi ngôn ngữ giữ phiên, draft, camera, khoanh
vùng, filter và batch; không phát sinh POST/PATCH lặp; kiểm tra lỗi đang hiển thị;
file xuất giống nhau giữa hai lựa chọn; UI mobile/keyboard dùng được. Build hoặc
test pass không phải chứng nhận độ chính xác AI hay hoàn tất mọi FR còn dang dở.
